This test case is used for checking the functionality of performance test 1 module.
*To perform the test case, run ws_server.py and multiple_clients_b1.py and multiple_clients_b2.py located in the same folder.
*Each of the files multiple_clients_b1.py and multiple_clients_b2.py will create 500 clients to connect to the server,
with a delay of 1 sec in between the connection of each instance.
*To run the same example with enabled reports, run ws_server.py and multiple_clients_b1_report.py and
multiple_clients_b2_report.py located in the same folder.
*If it is desired to run this example with oauth and TLS available, please go to oauth_tls folder and follow the instructions
in the README.txt file located there.
