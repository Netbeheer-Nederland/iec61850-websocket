This folder includes some extra files used for testing:

*ws_server_oauth_tls_direct.py includes a WS client instance in reversed mode that has oauth and TLS both enabled.
*ws_server_tls_direct.py includes a WS Server instance in direct mode that has TLS enabled
*ws_server_oauth_tls_direct.py includes a WS Server instance in direct mode that has TLS and OAUTH enabled
*ws_server_direct_oauth.py includes a WS Server instance in direct mode that has OAUTH enabled
