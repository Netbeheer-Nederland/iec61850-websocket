== Demo Setup

The demo runs from `examples/rti-demo`, either as local Python processes (`launch.py`) or as Docker containers
(`docker-compose.yml`). `examples/rti-demo/README.md` is the reference for both:

* *Quick Start* and *Services* - `launch.py`, service names and ports.
* *Docker* - network setup, locally built or published images, Keycloak, BFF state.
* *Hardware demo* - the IO devices on the Raspberry Pis, their IEC 61850 mapping and the demo flow.

Raspberry Pi preparation (GPIO, I2C, SPI, the I2C LCD backpack and its wiring) is in
`examples/rti-demo/modules/io/README.md`.
